# 🛒 RetailPro | Análisis de Ventas y Business Intelligence

## 📌 Descripción del proyecto

RetailPro es un comercio sobre el que se desarrolla el proyecto de análisis de datos orientado al estudio de información comercial y de ventas.

El proyecto incluye la creación y consulta de bases de datos en SQL Server, análisis de métricas de negocio y desarrollo de reportes en Power BI.

A través de este proyecto se trabajan conceptos como:

- Diseño y creación de bases de datos.
- Creación de tablas y relaciones.
- Claves primarias y claves foráneas.
- Inserción de datos.
- Consultas SQL.
- Agregaciones y métricas comerciales.
- `INNER JOIN` y `LEFT JOIN`.
- `UNION ALL`.
- Análisis de ventas, productos y clientes.
- Transformación y visualización de datos en Power BI.

---

## 🎯 Objetivo

El objetivo del proyecto es analizar información de ventas para obtener insights que permitan comprender el desempeño comercial del negocio.

Entre los principales indicadores analizados se encuentran:

- Análisis de facturación mensual.
- Ticket promedio.
- Ranking de productos.
- Identificación de clientes recurrentes.
- Análisis de ventas por canal.
- Identificación de productos y clientes sin ventas.

---

## 🛠️ Herramientas de Tecnología utilizadas:

SQL Server | SSMS | Power BI | Power Query | DAX

### SQL Server

Se utiliza para:

- Crear y administrar bases de datos.
- Crear tablas.
- Definir claves primarias y foráneas.
- Insertar registros.
- Realizar consultas SQL.
- Analizar información comercial.

### SQL Server Management Studio (SSMS)

Utilizado como entorno para ejecutar los scripts SQL y visualizar los resultados de las consultas.

### Power BI, Power Query y DAX

Utilizado para:

- Realizar procesos de transformación de datos.
- Crear modelos de datos.
- Definir relaciones entre tablas.
- Crear medidas y métricas.
- Desarrollar visualizaciones y dashboards.
